## 1. Architecture and decisions
LangGraph `StateGraph` is used because the workflow branches on explicit sufficiency and verification decisions and must terminate after bounded retries. Local embeddings are generated by all-MiniLM-L6-v2; normalized vectors are stored in FAISS. Ollama serves Qwen2.5-3B-Instruct locally. FastAPI exposes `/query` and `/documents`.

Rejected: hosted APIs (offline requirement), unbounded agent loops (termination requirement), notebook-only implementation (reproducibility).

## 2. State schema

| Field | Readers | Writers | Purpose |
|---|---|---|---|
| question | retrieval, grader, generator, verifier | initializer | original user input |
| search_query | retriever | initializer, recovery | rewriteable retrieval query |
| retrieved | grader, evaluator | retriever | ranked candidates |
| retained | generator, verifier, evaluator | grader | passages judged sufficient |
| sufficient | conditional router | grader | explicit sufficiency decision |
| sufficiency_reason | diagnostics | grader | decision explanation |
| answer | verifier, API | generator, regeneration, refusal | response |
| citations | verifier, API | generator, regeneration, refusal | source references |
| verified | verification router, API | verifier/refusal | groundedness check result |
| retries | retriever/router/API | initializer/recovery | bounded retrieval retries |
| verification_retries | router | initializer/regeneration | bounded verification retries |
| termination | API/evaluator | terminal node | final path reason |
| refused | API/evaluator | terminal node | refusal indicator |
| node_trace | diagnostics | all workflow nodes | node execution trace |

Paths: sufficient → generate → verify → answered; insufficient → one recovery → retrieve/grade → refused_no_context if still insufficient; verification failure → one regeneration → verify → refused_unverified if still unsupported.

## 3. Chunking and retrieval
Heading-scoped chunks preserve function/API entries. Markdown tables are emitted intact as separate chunks. Metadata includes document, section, heading anchor, version, source filename, chunk ID and chunk kind. Example table: `csv.Dialect`; example API entries: `pandas.read_csv` and `pandas.read_table`. ## 4. Grading, recovery, refusal and verification
A local model grades passage sufficiency and selects retained indices. One rewritten-query retry uses a larger top-k. The generator receives only retained passages and is instructed to cite chunk IDs. Verification checks claims against cited passages. One bounded regeneration is allowed.
